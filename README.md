# 🥞 StackIt - Modern Web Stack Application

![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white)
![Node.js](https://img.shields.io/badge/Node.js-339933?style=flat-square&logo=nodedotjs&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-blue?style=flat-square)

**StackIt** is a clean, type-safe full-stack application built with TypeScript, focusing on high developer efficiency, modular structure, and robust architecture.

---

## ✨ Features

- 🔒 **Full Type Safety:** Powered by TypeScript across frontend and backend layers.
- ⚡ **Modular Design:** Componentized structure for scalable feature development.
- 🧪 **Clean Code Principles:** Automated linting, code formatting, and type-checking.

---

## 🛠️ Quick Start

```bash
git clone https://github.com/chandrashekar-chandu/stackit.git
cd stackit
npm install
npm run dev
```
